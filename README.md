# Hardcore Teams Minecraft Plugin

The Hardcore Teams plugin is designed for Minecraft servers to enhance the hardcore gameplay experience. It features team management with blue and purple teams, automatic team assignment, item limits for totems, cobwebs, and ender pearls, and admin commands for server management. This plugin ensures a balanced and engaging gameplay environment by enforcing team-based strategies and resource limitations.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. **Join a Team**: Use the command `/team join <blue|purple>` to join either the blue or purple team.
2. **Leave a Team**: Use the command `/team leave` to leave your current team.
3. **Set Team Spawn**: Use the command `/team spawn` to teleport to your team's spawn point.
4. **Admin Commands**:
   - `/admin inventory <player>`: View the inventory of a specified player.
   - `/admin setteam <player> <blue|purple>`: Set a player to a specific team.
